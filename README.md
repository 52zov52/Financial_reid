## 🚀 Быстрый старт

### 1️⃣ Требования

| Компонент | Версия | Примечание |
|-----------|--------|------------|
| **Python** | 3.10+ | [Скачать](https://www.python.org/downloads/) |
| **pip** | 23.0+ | Обычно идёт в комплекте с Python |
| **Git** | Любой | Для клонирования репозитория |

### 2️⃣ Установка зависимостей

```bash
# Клонируйте репозиторий
git clone https://github.com/52zov52/Financial_reid.git
cd Financial_reid

# Создайте виртуальное окружение (рекомендуется)
python -m venv venv

# Активируйте виртуальное окружение
# Для Windows CMD:
venv\Scripts\activate
# Для Windows PowerShell:
.\venv\Scripts\Activate.ps1

# Установите зависимости
pip install -r requirements.txt
```

> 💡 Если файла `requirements.txt` нет, установите пакеты вручную:
> ```bash
> pip install flask flask-sqlalchemy flask-mail werkzeug
> ```

## 🔐 Настройка пароля администратора

Приложение **требует** установки переменной окружения для создания аккаунта администратора. Это необходимо для безопасности — пароль не хранится в коде.

### 🪟 Для Windows CMD:
```cmd
set FINANCIAL_RAID_ADMIN_PASSWORD=YourSecurePassword123!
```

### 🪟 Для Windows PowerShell:
```powershell
$env:FINANCIAL_RAID_ADMIN_PASSWORD="YourSecurePassword123!"
```

### 🐧 Для Linux/macOS:
```bash
export FINANCIAL_RAID_ADMIN_PASSWORD=YourSecurePassword123!
```

> ⚠️ **Важно:** 
> - Пароль должен быть сложным (минимум 8 символов, буквы + цифры + спецсимволы)
> - Переменная устанавливается **только для текущей сессии терминала**
> - При перезапуске терминала переменную нужно задать заново

## 👤 Вход в систему

### 🎮 Для обычных пользователей:
1. Откройте главную страницу
2. Введите никнейм (мин. 3 символа)
3. Нажмите **"Быстрый старт"** — аккаунт создастся автоматически

### 🔐 Для администратора:
1. Перейдите по ссылке **"Вход для админа"** на главной странице
2. Введите:
   - **Имя пользователя:** `admin` или `админ`
   - **Пароль:** тот, что вы задали в переменной `FINANCIAL_RAID_ADMIN_PASSWORD`
3. Нажмите **"Войти"**

> 🔒 После первого запуска аккаунт `admin` создаётся автоматически. Пароль изменить можно только через базу данных или переустановку переменной + удаление `database.db`.

## 🛠️ Управление приложением

### 🗄️ Сброс базы данных (если нужно начать с чистого листа):
```bash
# Остановите приложение (Ctrl+C)
# Удалите файл базы данных
del database.db

# Запустите приложение заново — база создастся автоматически
python app.py
```

### 🔄 Обновление контента станций:
Откройте файл `content.json` и отредактируйте вопросы, ответы или настройки станций. Изменения применяются **без перезапуска** приложения (при следующем запросе).

### 📊 Экспорт данных:
В админ-панели доступна кнопка **"Экспорт в CSV"** — скачивает таблицу со всеми пользователями, их прогрессом и статусами.

## ❓ Устранение неполадок

| Проблема | Решение |
|----------|---------|
| ❌ `ModuleNotFoundError: No module named 'flask'` | Установите зависимости: `pip install -r requirements.txt` |
| ❌ `FINANCIAL_RAID_ADMIN_PASSWORD not set` | Задайте переменную окружения перед запуском (см. выше) |
| ❌ `Address already in use` | Приложение уже запущено в другом окне или порт 5000 занят. Закройте другое окно или измените порт в `app.py` |
| ❌ `TemplateNotFound` | Проверьте, что папка `templates/` находится в корне проекта |
| ❌ Не создаётся аккаунт админа | Удалите `database.db` и перезапустите приложение с заданной переменной |
| ❌ Не работает вход под `admin` | Убедитесь, что вводите имя `admin` (латиницей) или `админ` (кириллицей) и правильный пароль |

## 🔒 Безопасность

- ✅ Пароль администратора **не хранится в коде** — только в переменной окружения
- ✅ Пароли пользователей хешируются через `werkzeug.security`
- ✅ Сессии защищены `SECRET_KEY` (замените на свой в продакшене!)
- ✅ Быстрый вход не позволяет занять системные имена (`admin`, `root` и др.)

> ⚠️ **Для продакшена:**
> 1. Замените `SECRET_KEY` на случайную строку
> 2. Включите `DEBUG = False`
> 3. Используйте Gunicorn/Uvicorn вместо встроенного сервера
> 4. Настройте HTTPS
