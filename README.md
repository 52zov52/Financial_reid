# Финансовый рейд - Образовательная игра

## Описание

Финансовый рейд — это интерактивное веб-приложение для обучения финансовой грамотности. Приложение представляет собой игру с несколькими станциями, где пользователи проходят различные задания по управлению бюджетом, кредитам и другим финансовым темам.

## Технологии

- **Backend**: Python, Flask
- **База данных**: SQLite (Flask-SQLAlchemy)
- **Frontend**: HTML, CSS, Jinja2 шаблоны
- **Аутентификация**: Встроенная система регистрации и входа пользователей

## Станции игры

### Станция 1: Бюджетный конструктор
Задача: Распределить бюджет (8000 ИК) по статьям расходов:
- Еда
- Транспорт
- Связь
- Развлечения
- Образование
- Сбережения (минимум 800 ИК)

### Станция 2: Кредитный лабиринт
Задача: Выбрать наиболее целесообразные кредиты для развития из предложенных вариантов.

### Станция 3: Ребусы
Задача: Разгадать финансовые ребусы.

## Установка и запуск

### Требования
- Python 3.7+
- pip

### Установка зависимостей

```bash
pip install flask flask-sqlalchemy
```

### Запуск приложения

```bash
python app.py
```

Приложение будет доступно по адресу: `http://localhost:5000`

## Использование

1. **Регистрация**: Создайте новую учётную запись на странице регистрации
2. **Вход**: Войдите в систему с вашими учётными данными
3. **Прохождение станций**: Последовательно проходите все станции
4. **Просмотр результатов**: После завершения всех станций просмотрите свои результаты

## Функционал

- Регистрация и аутентификация пользователей
- Система прогресса по станциям
- Подсчёт баллов за правильные ответы
- Сохранение прогресса в базе данных
- Админ-панель для просмотра результатов пользователей
- Экспорт результатов в CSV
- Адаптивный дизайн

## База данных

Приложение использует SQLite базу данных `database.db`, которая создаётся автоматически при первом запуске.

### Модель User

| Поле | Тип | Описание |
|------|-----|----------|
| id | Integer | Уникальный идентификатор |
| username | String(80) | Имя пользователя |
| email | String(120) | Email |
| password_hash | String(200) | Хэш пароля |
| group | String(50) | Группа |
| current_station | Integer | Текущая станция |
| score | Integer | Общий счёт |
| answers | Text | Ответы пользователя (JSON) |
| is_finished | Boolean | Завершена ли игра |
| created_at | DateTime | Дата создания |
| last_login | DateTime | Последний вход |

## Конфигурация

Основные настройки находятся в `app.py`:

```python
app.config['SECRET_KEY'] = 'financial-reid-secret-key-2024-change-in-production'
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///database.db'
```

**Важно**: Перед использованием в продакшене измените `SECRET_KEY` на уникальное значение!
